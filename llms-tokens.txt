# Mola UI: tokens

> Every design token in `src/styles/tokens.css`, with its role and its value in each theme. Part of the agent docs for `@demogar/mola-ui`; the index is https://demogar.github.io/molaui/llms.txt.

## Tokens

Every custom property in `src/styles/tokens.css`, the one file allowed a colour literal. A colour is a `light-dark()` pair, resolved here to the hex it paints in each theme by the resolver the contrast test runs; a value that depends on what is underneath (a translucent mix, a shadow) is shown as written. The role is the section of the file a token sits in, and its own note where it has one. In markup, use the Tailwind utility: `--cloth-pale` is `bg-cloth-pale`, `--ink-muted` is `text-ink-muted`.

## Density

Density is an attribute, `data-density`, on `<html>` or any subtree. Comfortable is the default and uses the values above; the other two redefine these:

### `data-density="compact"`

- `--spacing`: `0.21875rem`
- `--text-2xs`: `11px`
- `--text-xs`: `11.5px`
- `--text-sm`: `12.5px`
- `--text-base`: `13px`
- `--text-lg`: `15px`
- `--text-xl`: `18px`
- `--control-h`: `28px`
- `--control-h-sm`: `24px`
- `--control-h-lg`: `36px`
- `--control-px`: `10px`
- `--row-h`: `30px`

### `data-density="spacious"`

- `--text-xs`: `13px`
