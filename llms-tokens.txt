# Mola UI: tokens

> Every design token in `src/styles/tokens.css`, with its role, its value in each theme, and for a colour its scopes, its utilities and the pairings it is promised. Part of the agent docs for `@demogar/mola-ui`; the index is https://demogar.github.io/molaui/llms.txt.

## Tokens

Every custom property in `src/styles/tokens.css`, the one file allowed a colour literal. A colour is a `light-dark()` pair, resolved here to the hex it paints in each theme by the resolver the contrast test runs; a value that depends on what is underneath (a translucent mix, a shadow) is shown as written. The role is the section of the file a token sits in, and its own note where it has one. In markup, use the Tailwind utility in the "Use as" column: each colour token is scoped to the jobs it does, and only those utilities are valid. `--cloth-pale` is `bg-cloth-pale` and never `text-cloth-pale`; `--ink-muted` is `text-ink-muted`, or `bg-ink-muted` for a mark.

## Scopes

Every colour token has one or more scopes (`src/tokens/scopes.ts`). Tailwind will compile any colour utility for any token, so the scope, not the compiler, says which are right. The same scopes are exported to Figma as variable scopes in `tokens/mola.tokens.json`.

| Scope | What it is | Tailwind | Figma |
| --- | --- | --- | --- |
| `surface` | A ground that carries content: a page, a panel, a card, a wash, a filled layer. | `bg-` | `FRAME_FILL` `SHAPE_FILL` |
| `text` | The colour of words, and of icons that inherit `currentColor`. | `text-` `placeholder-` `caret-` | `TEXT_FILL` |
| `edge` | A line: a keyline, a divider, an underline, a current-item bar, the revealed band of a cut. Mola draws most edges with `box-shadow`. | `border-` `border-x-` `border-y-` `border-t-` `border-b-` `border-s-` `border-e-` `border-l-` `border-r-` `divide-` `outline-` `ring-` `decoration-` `stroke-` `cut-` `bar-start-` `bar-bottom-` | `STROKE_COLOR` `EFFECT_COLOR` |
| `mark` | A small filled graphic that is not a region: a status dot, a swatch key, a switch thumb, a rule drawn as a 1px box. | `bg-` `fill-` `stroke-` | `SHAPE_FILL` |
| `overlay` | A translucent fill over content the system cannot know: a scrim over an image, the backdrop behind a modal. | `bg-` | `FRAME_FILL` `SHAPE_FILL` |
