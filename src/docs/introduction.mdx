## What this is

Mola UI is a React component library and token system for **internal platforms and AI-native
products**: admin tools, operator consoles, knowledge bases, agent run monitors. It ships:

- **Tokens** — one CSS file, two themes declared once with `light-dark()`, three densities, every
  contrast ratio measured and enforced by a test. Exported to W3C design-token JSON for Figma.
- **68 documented components** (147 exported parts) — actions, forms, overlays, navigation, data display, and an application
  shell — built on [Base UI](https://base-ui.com) primitives for behaviour and accessibility,
  styled with Tailwind v4.
- **An AI interface layer** — streaming text, message threads, a composer that turns into a stop
  button, tool-call cards with human approval, long-running agent run timelines, reasoning
  disclosure, citations, token budgets, and an honest way to show uncertainty.

## Where the name comes from

A **mola** is the hand-sewn textile of the Guna people of Panama. The word names both the panels
and the blouse that Guna women make and wear. Layers of cotton are basted together, a design is
cut through the upper layers, and every edge is turned under and hemmed by hand to reveal the
colour beneath. Nothing in a mola is blended, tinted or soft. The technique is passed down from
generation to generation, and a single panel can take months.

A mola is more than decoration. When Panama's government tried to stop Guna women wearing their
traditional dress, making and wearing molas became an act of resistance, and the Guna Revolution
of 1925 won the Guna autonomy over their land and culture. The mola is protected today under
Panama's Law 20 of 2000 as collective intellectual property of the Guna people.

### Why this name, and how we hold it

Mola UI is not made by Guna people and does not speak for them. It carries the name out of
respect: to its author, the mola is one of the most authentic expressions of Panamanian culture,
a craft to be honoured rather than borrowed lightly. The name also fits what this project tries to be.
A mola carries a people's identity into everyday life. Each one is made by hand and is unique,
yet every one belongs to the same tradition, because it comes from a shared method. A design
system does a humbler version of the same thing: it carries an identity and the knowledge of how
to make things well into every product, so each screen is its own while plainly belonging to the
same family.

In practice: Mola UI borrows the **method, not the motifs**. Its interface reproduces no Guna
designs, symbols or patterns. The photograph above is here only to show where the name comes from,
credited to the women who make molas and to the photographer. The project claims no rights over
the mola, and names its source wherever the name appears. If
you want a mola, buy one from Guna artisans.

### What the method gives the interface

That method became the system's grammar:

| In the cloth | In the interface |
| --- | --- |
| The black top layer | `--ink`: the foreground, and every keyline |
| The cut edge | `box-shadow` keylines, never `border` — so an edge can grow without reflowing |
| The revealed band | `cut-band`: hover and selection reveal the layer beneath |
| *Relleno* — filler slits | the divider, the empty state, and (moving) the "working" state |
| *Diente* — the sawtooth seam | the edge where one ground is cut away from another |
| No curve anywhere | zero radius, everywhere, no exceptions |

It began as the design system for [Must Do Panama](https://www.mustdopanama.com), an editorial
travel guide. Mola UI is that system **carried from an editorial site into product software**:
the same identity, re-argued for information density, a dark theme for all-day use, and the
states AI work actually produces.
