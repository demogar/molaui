# The cut

<DecisionsBehind foundation="Foundations/The cut" />

The devices that make this a mola rather than a palette swap. Each is a Tailwind v4 `@utility`
in `src/styles/cloth.css`, so it composes with everything else.

## Keyline and revealed band

`shadow-cut` is the blade edge. `cut-band` adds the revealed layer and a second edge —
concentric, never offset: a mola's layers are stacked, so the reveal goes all the way around.
`band-*` chooses the colour beneath, per element.

    <div className="grid size-24 place-items-center bg-cloth-pale cut-band band-oro text-xs">band-oro</div>
    <div className="grid size-24 place-items-center bg-cloth-pale cut-band band-danger text-xs">band-danger</div>
    <div className="grid size-24 place-items-center bg-cloth-pale cut-band band-anil text-xs">band-anil</div>
    <div className="grid size-24 place-items-center bg-cloth-pale cut-band band-verde text-xs">band-verde</div>
  </div>
</Specimen>

Edges are `box-shadow`, not `border`, because the signature hover *grows* the edge by several
pixels. A border would reflow the row; a shadow does not move a single neighbour.

`band-accent` is the gold reveal by name, and `band-danger` the red one: on a product screen rojo
is only ever danger ([ADR 0008](?path=/docs/decisions-0008-the-rojo-register--overview)),
so a seam that means "this destroys something" says `band-danger`, and `band-rojo` is left to
editorial pages.

## Edges

Every other edge is a box-shadow too, and each has a name, so a component says which edge it means
rather than typing a shadow. The components used to type 70 of them in place, with 33 `rtl:` twins
to flip the sign on a right-to-left page; a forgotten twin was a bar on the wrong side that no test
saw. The named edges carry their own right-to-left form.

| Utility | Draws | Width |
| --- | --- | --- |
| `rule-t` `rule-b` `rule-s` `rule-e` | A decorative keyline on one side, between rows or panes. `-soft` for `--keyline-soft` | `--rule-w`, 1px |
| `cut-t` `cut-b` `cut-s` `cut-e` | The blade edge on one side: a table header's foot, an app bar, segments | `--cut-w`, 1.5px |
| `bar-start-<colour>` `bar-bottom-<colour>` | The current item, or a region a status owns | `--bar-w`, 3px |
| `cut-<colour>` | A keyline all the way round in a colour: an outline badge, a thumb | `--cut-w` |
| `cut-frame` | A container's frame: the cut on its own, the decorative keyline inside another frame (see below) | `--cut-w`, or `--rule-w` nested |
| `cut-thin` `rule-ring` | A 1px ink ring for a mark too small for the cut; a 1px decorative ring | `--rule-w` |
| `focus-ring` `focus-ring-inset` | The focus ring, as an edge, so it adds to the others | |

`s` and `e` are the start and end of the reading direction. Each side is its own slot, so edges on
different sides add up (`cut-t cut-b`, `bar-start-ink rule-b-soft`) and a focused current item keeps
its bar while the ring is drawn. In forced colours a ring comes back as an outline and a one-sided
edge as a border on the same side.

## One cut per nesting level

The cut is the edge of something a pointer can touch, and a container is the region that edge
bounds. Put a framed container inside another and draw both with the cut, and the screen gets
frames inside frames of the same ink and weight: an agent run holding a tool call holding a
code block was three identical 1.5px edges, and the eye could not tell which belonged to which.
The code being inspected, innermost, had the weakest claim to its own edge.

So the outermost container keeps the cut, and every container inside it draws the decorative
keyline instead. A container whose ground would equal its parent's steps down to the page's
ground as well, so it reads as set into the outer one rather than stacked on it. `cut-frame` does
this by itself: it recognises the frame around it (another `cut-frame`, or a `Panel` with an
edge) from the page, so nothing has to be passed down, and a dialog portaled out of a run is not
nested. `nested:` applies a class only to a frame inside another, which is how the ground steps
down: `bg-cloth-pale cut-frame nested:bg-cloth`.

`AgentRun`, `ToolCall`, `CodeBlock`, `ChangeReview`, `FileDiff`, `SideBySideDiff`, a standalone
`Stat`, a framed `Table` and `Panel` frame themselves this way. Controls are not containers: a
button, a field, a tool call's own header and a source card keep the cut wherever they sit.
Popups keep it too, since their elevation already separates them from what they cover.

## Hover

Two gestures, chosen by whether the control has an edge:

- **A cut shape grows its band.** Buttons, fields, checkboxes, chips and cards reveal the layer
  beneath on hover — gold by default, never red.
- **An edgeless control washes.** Ghost buttons, rows, menu items and disclosure triggers take
  `--ink-soft` behind them, and secondary text steps up to ink.

Hover is never red, except on the danger button that is already red. Red means something can be
lost or has failed; a heading or a field that flashes red as the pointer crosses it reads, for a
moment, as an error. The editorial system turned links and accordion titles red on hover, and the
product system dropped it for that reason.

## Relleno — the filler slit

In a finished mola the negative space is packed with narrow slits cut to a lower layer. Here it is
the divider (in place of a hairline), the empty-state texture, and — moving — the **working**
state: work is happening and its size is unknown.

  </div>
</Specimen>

The layer colour is the *ground* and ink is the *slit*. Inverted — thick colour bars on black — the
strip reads as hazard tape. That was the first build of it.

## Diente — the sawtooth seam

Where a top layer is cut back. Used only on major seams, where the page ground gives way to a
filled panel; in a real mola this edge is the slow, expensive part, and there are only a few.

## Display, cut

The mola applied to letterforms: fill, then the revealed band, then the ink edge. **Only on a
filled panel**, one per page. On light cloth a bold sans in a gold-and-black outline stops reading
as appliqué and starts reading as a comic-book sticker.

  </p>
</Specimen>

## Focus

A third band: two-tone, so it survives on any ground — a cloth gap, then ink. Square, because the
radius is zero. In Windows High Contrast, where shadows are removed, a system-coloured outline
takes over.
