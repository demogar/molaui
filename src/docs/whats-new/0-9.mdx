# What's new in 0.9

<ReleaseStatus version="0.9.0" />

0.9 changes how the interface reads, with no change to props or tokens. The full list is under
*Everything in 0.9.0* at the end of this page, and on the
[Changelog](?path=/docs/mola-ui-changelog--overview).

## Capitals name categories; everything else is sentence case

Buttons, badges, column headers, form labels, stat names and message authors used to be set in
small, wide, tracked capitals, the same register as the labels that name a group or a section. On
a busy screen everything was lettering, so nothing stood out. They are now in sentence case,
semibold, at the drawn width of Archivo. Capitals are kept for what names a category: navigation
groups, menu and select groups, section labels, and the kind of an agent's step.

Translations gain the most. The stylesheet no longer sets the case of a word a person acts on, so
a German noun keeps its capital and Turkish keeps its dotted İ, and a button label is about 40%
narrower than it was in capitals. The decision and what was measured are in
[ADR 0017](?path=/docs/decisions-0017-capitals-name-categories--overview), and
[Typography](?path=/docs/foundations-typography--overview) shows both registers.

### What to check in your app

- **Words you pass are shown as written.** A badge or column header that relied on the capitals,
  such as `<Badge>{run.status}</Badge>` with `failed`, now shows `failed`. Pass the word a person
  should read: `Failed`.
- **Buttons are a size step larger and much narrower.** Control heights are unchanged, so layouts
  hold; a toolbar that was tight for space has more room.
- **Want capitals back somewhere?** Pass `className="rotulo"`. `cn()` treats `rotulo` and the new
  `etiqueta` utility as one group, so yours replaces the component's.
