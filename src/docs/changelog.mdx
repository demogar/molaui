# Changelog

## 0.1.0 — 2026-10-05

First public release.

- Tokens: two themes in one declaration (`light-dark()`), three densities, contrast contract

- Components: actions, forms, overlays, feedback, navigation, data display, application shell.
- AI interface layer: streaming text, threads, composer, tool calls with approval, agent run
  timeline, reasoning, citations, token usage, confidence.
- Extracted from the Mola design system of mustdopanama.com and re-argued for product density.
